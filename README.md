# うちの子、おるすばん中。

飼い主が留守のあいだ、「うちの子」に似せた犬を操作して、部屋でちょっとだけ（？）いたずらするブラウザゲームです。
Three.js 製で、スマホ（タッチ）と PC（キーボード）の両方で遊べます。

- ティッシュをくわえて走ると、ティッシュがどこまでも伸びていきます
- クッションは長押しでぶんぶん振り回すと中綿が飛び、はなすと投げられます
- 体当たりや転がったボールで物が倒れ、倒れた物がさらに別の物を倒すと「連鎖」になります
- ご主人が帰ってきた瞬間の犬の様子で結末が変わります（しらんぷり成功／現行犯／おひるね中…）
- 最後に「お留守番報告書」が出て、被害総額・犬の顔・事件を画像で共有できます

## 起動方法

Node.js 18 以上が必要です。

```bash
npm install
npm run dev      # 開発サーバー（同じWi-Fiのスマホからは表示された Network のURLで開けます）
```

公開用のビルド:

```bash
npm run build    # dist/ に静的ファイルを出力（相対パスなので GitHub Pages などにそのまま置けます）
npm run preview  # ビルド結果の確認
```

## 操作方法

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面の左側をなぞる（出てくるスティック） |
| くわえる / はなす | Space（J・Z・Enterでも可） | 右下の大きいボタン |
| ぶんぶん・かみかみ → 投げる | Space を長押し → はなす | 大きいボタンを長押し → はなす |
| はしる（体当たり） | Shift（K・Xでも可） | 右下の「はしる」 |
| 一時停止 | Esc / P | 右上の II |
| もう一回（報告書の画面で） | R | 「もう一回おるすばん」 |

近くに何もないときに「くわえる」を押すと「わん！」と鳴きます。

## 遊びのしくみ

1回のおるすばんは約2分（ゲーム内 13:00〜18:00）です。

- **被害額**：ティッシュは引き出した枚数、クッションは綿が飛ぶたび、倒れた物・割れた物はそれぞれの金額が加算されます。
- **連鎖**：いたずらが2.4秒以内に続くと連鎖になり、倍率が ×1.5、×2.0 … と上がっていきます（最大 ×5）。
  倒れた物は倒れた先にある物を巻き込むので、「何をどちら向きに倒すか」で結果が変わります。
- **仕掛けの配置**：段ボールの並び方は回ごとに変わり（窓辺の植木鉢へ／テーブルへ／ゴミ箱へ）、毎回ちがう連鎖を探せます。
- **グラッ…**：歩いてぶつかると物が揺れるだけで、「はしる」で体当たりすると倒れます。揺れたら倒せる合図です。
- **お宝**：自分のベッドに運んだ物（スリッパなど）は、帰宅時に「お宝ボーナス」（1つにつき +10%）になります。
- **帰宅**：残り15秒で足音が聞こえます。ベッドに戻って何もくわえずにいれば「しらんぷり成功」、
  何かをくわえたままなら「現行犯」です。ぎりぎりまで連鎖を狙うか、戻るかを選べます。
- **ひなたぼっこ**：日だまりやベッドでしばらく何もしないと、お昼寝します（お昼寝中は時間が早く進みます）。
- **じけん図鑑**：20種類の「じけん」があり、初めて起こすとボーナスが入ります。未発見のじけんはヒント付きで表示され、
  毎回の「今日のお題」も未発見のじけんから選ばれます。

名前・犬種・毛色・耳・しっぽ・もこもこ具合・体型を選べます。うちの子の設定、自己ベスト、図鑑の進み具合は
ブラウザ（localStorage）に保存されます。ログインは不要で、遊ばないことによるペナルティもありません。

## 共有

報告書の「画像でシェア」で、報告書画像（1080×1350）を生成して Web Share API で共有します。
共有に対応していない環境では、画像のプレビューとダウンロードに切り替わります（スマホは画像を長押しで保存できます）。

## 技術メモ

- Three.js r186 + Vite。犬・家具・部屋はすべてコードで生成したローポリのモデルで、画像やモデルの外部素材は使っていません。
- 効果音と BGM は WebAudio でその場で合成しています（音源ファイルなし）。
- 物理は軽量な自前実装です（床の上の円・箱の当たり判定、転倒アニメーション、倒れた先の巻き込み判定）。
- 画質は「きれい／ふつう／かるい」の3段階で、フレームレートが落ちると自動で下げます（ピクセル比・影の解像度・影の有無）。
  影を切った画質でも、床の日だまりは別の方法で描いて雰囲気を保っています。一時停止メニューから手動でも変更できます。
- フォントは Google Fonts の「M PLUS Rounded 1c」（SIL Open Font License 1.1）を読み込み、読めない場合は端末の丸ゴシック体などを使います。
- Three.js は MIT ライセンスです。

### ファイル構成

```
index.html          画面の骨組み（HUD・各画面）
src/main.js         レンダラ・ライト・画質調整・画面遷移・撮影
src/game.js         ゲーム進行（おるすばん、スコア、連鎖、帰宅演出、報告書データ）
src/world.js        部屋の中の物（くわえる・転がる・倒れる・巻き込み）
src/tissue.js       ティッシュが伸びる帯
src/dog.js          犬の操作と手続きアニメーション（歩き・しっぽ・耳・表情）
src/dogModel.js     犬のモデル生成（犬種・毛色・耳・しっぽ）
src/room.js         部屋・家具・窓の光
src/fx.js           綿・破片・キラキラ・ポップアップ・吹き出し
src/camera.js       カメラ（追従・タイトル・うちの子編集・帰宅演出）
src/ui.js           HUD・報告書・図鑑・編集画面
src/share.js        共有用画像の生成
src/audio.js        効果音・BGM（WebAudio合成）
src/incidents.js    じけん図鑑の定義
```
