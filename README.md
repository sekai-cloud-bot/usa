# 駅まで、おむかえ。

おるすばん中の犬が、窓のすき間から脱走して、夕方の町をぬけ、18時の電車で帰ってくる飼い主を駅までむかえにいく 3D アドベンチャーです。
Three.js 製。PC とスマホのブラウザで遊べます。外部の画像・音声素材は使っていません（町・人・動物・空・音はすべてコードで生成）。

## 起動方法

必要なもの：[Node.js](https://nodejs.org/) 18 以上

```bash
git clone https://github.com/sekai-cloud-bot/usa.git
cd usa                       # ← package.json があるフォルダで実行します
git checkout claude/dog-game-threejs-mrp36o
npm install
npm run dev                  # http://localhost:5173 を開く
```

- スマホで試すとき：`npm run dev` は `--host` 付きなので、表示される `Network:` の URL を同じ Wi‑Fi のスマホで開きます。
- 公開用ファイル：`npm run build` で `dist/` に出力されます（相対パスなので GitHub Pages などのサブフォルダでも動きます）。`npm run preview` で確認できます。
- Windows で `ENOENT ... package.json` と出たら、`cd` でこのフォルダに移動してから実行してください。

## うちの子をえらぶ

犬種ではなく「タイプ（体つき）」から選び、細かいところを組み合わせて、自分の子に近づけます（ミックスの子も作りやすいように）。

| 項目 | 選べるもの |
|---|---|
| タイプ | ふわふわ わたあめ（ビションみたいな）／もふもふ まん丸（ポメ・スピッツみたいな）／ころころ短毛（チワワ・子犬みたいな）／くるくる巻き毛（トイプードルみたいな）／どっしり胴長（ダックス・コーギーみたいな）／すらっと中型（柴・ミックスみたいな）／おおきいふわふわ（ゴールデン・サモエドみたいな）／おおきいつやつや（ラブラドールみたいな） |
| おおきさ | ちいさめ／ふつう／おおきめ（大型犬のタイプは、そのまま大きい） |
| 毛の色 | 9色 |
| もよう | いちいろ／おなか白／ほっぺ白（まろまゆ）／ぶち／くつした |
| 耳 | ピン／おおきい／たれ／ふわたれ／ながたれ |
| しっぽ | ふさふさ／くるりん／ぽんぽん／ほそ |
| もこもこ | 毛の量（短い毛の子は、ビロードのように なめらか） |

タイプを選ぶと、耳・しっぽ・もよう・毛の量が その子らしい組み合わせになり、そこから変えられます。前のバージョンで犬種を選んでいた場合は、近いタイプに読みかえて引き継ぎます。

### 犬をまわして確かめる

犬は、ベッドから はなれた あいている床に座ります。まわりを ぐるっと見られるので、しっぽや耳も うしろ・よこから確かめられます。

| 操作 | PC | スマホ |
|---|---|---|
| じどう回転 | 画面下の「じどう回転」でON/OFF（設定は保存）。さわっている間は止まり、はなして少したつと また回る | 同じ |
| 手でまわす | ドラッグ（左右で回転、上下で高さ）・矢印キー／WASD | カードの外の空いた所をなぞる |
| ズーム | ホイール | 2本ゆびで ひらく・とじる |
| ◀ ▶ | 45度ずつ回る | 同じ |
| まえ／よこ／うしろ | その向きへ回る | 同じ |

「しっぽ」を選ぶと斜めうしろへ、「耳」を選ぶと斜めまえへ、自動で回りこんで見せます。

## 遊び方

1. **プロローグ**：「6時の電車で帰るからね」。目がさめると、リビングの窓が少しあいています。鼻でおして庭へ。
2. **空撮のタイトル**：庭に出た瞬間、カメラが庭の上から空へ上がって町と駅が見え、タイトルが出ます。
3. **脱出**：庭の柵の下のやわらかい土を掘って（長押し）、路地へ。
4. **においをたどる**：くんくんすると世界の色がぬけて、飼い主のにおいが金色の光の道になります。まだ見ていない「できごと」の場所からは、空へのびる光の柱が立ちます（壁ごしでも見えます）。近くに うまっている「おたから」の場所も見えます。
5. **寄り道（できごと 33 こ）**：町じゅうに、しずく型の印（ピン）が浮かんでいます。色で種類がわかります。
   - ピンク＝ともだち ／ 黄＝みつけた物 ／ 緑＝よりみち ／ 紫＝けしき
   - 近づくとヒントが出て、できたら写真つきの「思い出カード」が出ます。
6. **なかま**：友だちになった動物は、駅まで いっしょに来てくれます（下の「なかま」）。
7. **おむかえ**：改札の前でおすわりすると、⏩ 早送りで 18:00 まで待てます。電車が高架に入ってきて、改札から出てきた飼い主にかけよると再会の演出。なかまがいると、あの人のまわりに集まって、最後は みんなで記念写真。
8. **おむかえ日記**：再会の写真・きょうの称号・寄り道の思い出（アルバム）・おみやげ・できごとの数がカードになり、シェア（Web Share）または画像保存ができます。

### なかま（いっしょに駅へ）

| なかま | なかまになる方法 | ついてきかた |
|---|---|---|
| コロンちゃん（コーギーと柴犬のミックス。ピンクのハーネス） | さくら公園で ワン → 得意の「ころん」から おいかけっこ。つかまえると ころんと へそ天 | 少しうしろの横を、おしりを ふりふり 歩く。歩きながら ワンと言うと いっしょに ワン、止まって ワンと言うと「ころん」。駅まで いっしょに行くと、あの人の おみやげが コロンちゃんと おそろいの ハーネスに |
| ねこのミケ | 路地の塀の上で あいさつ | 少しはなれて ついてくる。水には入らず、岸で待つ |
| ハトのポッポ | 駅前のハトの群れに かけこむ | 頭の上に のる。走ると つばさで バランス |
| カルガモのひな | 商店街で そっと近づいて おすわり | すぐうしろを よちよち。走ると はぐれて なく（もどれば また ついてくる）。池に つれていくと お母さんの所へ |

- なかまは犬の歩いた道（足あと）を たどるので、壁をすりぬけません。犬がおすわりすると いっしょに おすわりします。
- 再会では、あの人が なかまのことも話してくれて、最後は みんなで記念写真。日記にも「○○と いっしょに」と のこります。

### だるまさんが ころんだ（河川敷）

- 一本木の前の子どもたちが遊んでいます（見ていると、ルールが わかります）。近くで ワンと言うと なかまに入れてもらえます。
- 白い線に ならぶと はじまります。オニが「だるまさんが ころんだ」と言う間だけ動けて、ふり向いたら ピタッと止まる（画面上の文字が赤くなります）。動いたら スタートの線へもどります。
- 言いかたは「ふつう」「はやい」「ゆっくり→はやい」「が で ためる」の4つ。オニに近づいて タッチ（E）できたら かち。

### おたから（たからばこ）

- 町の20か所に おたからが うまっています。くんくんすると、10m 以内の「あやしいにおい」（もりあがった土と、黄緑のにおい）が見えます。
- その上で アクション長押し（E／ほる）で ほり出せます。はじめての物は「たからばこ」へ（ずっと残ります）。もう持っている物の所からは おやつが出て、少しのあいだ足が速くなります。
- くんくんしていなくても、すぐそばを通ると 犬の鼻が ぴくっと動きます。
- たからが 5こ・10こ・15こ・20こ になると、きせかえ（むぎわらぼうし・まるメガネ・ちょうネクタイ・金の王冠）がもらえます。一時停止の画面で、たからばこ と この回で見つけた場所が見られます。

### きせかえ

頭（花かんむり・むぎわらぼうし・金の王冠）／顔（まるメガネ）／首（赤いバンダナ・金のすず・ちょうネクタイ）／体（おそろいハーネス：コロンちゃんと 駅へ）の4か所に、1つずつ。ハーネスは その子の体の形に合わせて作るので、どのタイプにも ぴったり。もらった物は すぐに身につけ、次からも そのまま出発します。「うちの子をえらぶ」で つけたり はずしたりできます（まだの物は、もらい方のヒントが出ます）。

### きょうの称号

その日の おむかえの しかたで、称号が もらえます（16種類）。たとえば「ずぶぬれ探検家」（ぬれたまま おむかえ）、「おむかえ 大行列」（なかま3びき）、「ピタッと名人」（だるまさんが ころんだ で いちども動かずに勝つ）、「伝説の 金のほね」など。はじめての称号は NEW が つき、結果の画面と 日記の写真に のります。

### 時間の流れ

- 16:30 に出発し、18:00 に電車が着きます（遊んでいる時間で 約12分）。
- 時間は一定の速さで進み、演出（イベントの映像）の間は止まります。
- 早く着いたら、改札の前でおすわりすると ⏩ 早送りで 18:00 まで待てます。
- 18:00 になると、どこにいても電車は着きます。遅れても失敗にはならず、あの人は改札の前で待っていてくれます（再会のセリフと日記が変わります）。

### おみやげ（10種類）

くわえて持っていった物で、飼い主のセリフと日記が変わります：なし／りっぱな枝／ぴかぴかの王冠／だれかのボール／桜の枝／ひまわり／あの人のくつした／100円玉／おみくじ（大吉）／ガチャの柴犬。

もらったバンダナ・花かんむり・金のすずは、次回から身につけて出発します。

## 保存されるもの（localStorage）

うちの子（名前・タイプ・大きさ・毛色・もよう・耳・しっぽ・もこもこ）、見たできごと、出会った友だち、見たおみやげの種類、もらったきせかえ と 身につける物、たからばこ、もらった称号、クリア回数、最速到着時刻、音と画質の設定。前作「うちの子、おるすばん中。」で作った子がいれば引き継ぎます。

## 画質

- 高：MSAA＋GTAO（環境光の遮蔽）＋光の筋（夕日の光芒）＋ブルーム＋カラーグレーディング（演出中はミニチュア風のぼかし）、影 4096、犬の毛 7 層
- 中（スマホの初期値）：GTAO なし、解像度 1.5 倍まで、影 2048、毛 5 層
- 低：ポスト処理なし、解像度 1 倍、影 1024、毛 3 層
- 「自動」では 1 秒ごとに FPS を測り、38fps 未満が 3 秒続くと 1 段下げます。一時停止メニューから手動でも切り替えられます。

見た目の工夫：空の色から作る環境光（IBL）、夕日が霧にとける大気の散乱、葉や草の透過光、テクスチャから作る凹凸（アスファルト・石・レンガ・瓦）、ガラスや車の塗装の映りこみ。犬は 距離関数（SDF）で胴・首・脚・頭をやわらかく溶けあわせた、つなぎ目のない1枚の体（もこもこの子は面そのものが わたのように でこぼこ）に、光がやわらかくまわりこむ毛の陰影と、輪郭だけ ふわっと見える毛並み。
