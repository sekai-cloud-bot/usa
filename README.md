# うちの子、おるすばん中。

昼休みに「みまもりカメラ」で家をのぞいて、留守番中のうちの子の**決定的瞬間**を撮るブラウザゲームです。
Three.js 製で、スマホ（タッチ）と PC（マウス・キーボード）の両方で遊べます。

- うちの子は、自分の気分（退屈・眠気・おなか・興奮）と性格で勝手に過ごします。
  ティッシュを引き出す、クッションを振り回して破裂させる、スリッパをベッドに運ぶ、ズーミー、日だまりでへそ天…
- いたずらの前には「うずうず」（おしりを上げる）で予告します。カメラを向けて、その瞬間を待ちかまえます。
- おやつ・名前を呼ぶ・レーザーで、うちの子にちょっかいを出せます。いたずらの直後に呼ぶと「無実の顔」でこっちを見ます。
- 撮った写真は「瞬間」と「写り方」（大きさ・顔の向き・ブレ・隠れ）で★1〜3。24種類の瞬間をアルバムに集めます。
- 昼休みの最後に表紙の1枚を選んで、「みまもり日記」画像として共有できます。

## 起動方法

Node.js 18 以上が必要です。

```bash
git clone -b claude/dog-game-threejs-mrp36o https://github.com/sekai-cloud-bot/usa.git
cd usa
npm install
npm run dev      # 表示された Local のURLをブラウザで開く（スマホは同じWi-Fiで Network のURL）
```

公開用のビルド:

```bash
npm run build    # dist/ に静的ファイルを出力（相対パスなので GitHub Pages などにそのまま置けます）
npm run preview  # ビルド結果の確認
```

## 遊びのしくみ

- 1回の昼休みは約2分半（ゲーム内 12:00〜13:00）、撮影枠は15枚です。途中で「おわる」を押して終えることもできます。
- 写真の中央の枠（4:3）が写る範囲です。画面の外で物音がすると、ふちに方向が表示されます。
- **写り方**：大きさ・中央寄り・顔がこっちを向いているか（後ろ姿がいい瞬間もあります）・カメラを動かしながら撮っていないか・家具に隠れていないか。
- **ちょっかい**：おやつは5こ（近くに投げると空中キャッチ）、レーザーは電池が約12秒、名前は何度でも呼べます（呼びすぎると…）。
- **性格**：やんちゃ／くいしんぼう／ねぼすけ／あまえんぼう。いたずらの頻度、よく寝るか、呼ぶと来るかが変わります。
- 部屋の段ボールの並びは回ごとに変わり（窓辺／テーブル／ゴミ箱へ続くドミノ）、途中でインターホンが鳴ることもあります。
- アルバム（24種類）には瞬間ごとのベスト写真が残ります。未撮影の瞬間はヒント付きで表示されます。
- うちの子の設定・アルバム・ベストスコアはブラウザ（localStorage）に保存されます。ログインは不要です。

## 共有

アルバム画面の「表紙をシェア」で、表紙の写真を使った「みまもり日記」画像（1080×1350）を作り、Web Share API で共有します。
共有に対応していない環境では、画像のプレビューとダウンロードに切り替わります（スマホは画像を長押しで保存できます）。

## 技術メモ

- Three.js r186 + Vite。犬・家具・部屋はすべてコードで生成したローポリのモデルで、画像やモデルの外部素材は使っていません。
- うちの子の行動は `src/ai.js` のジェネレータで書いた手順（近づく → うずうず → 実行 → ちらっ）と、欲求・性格による選択でできています。
- 撮影の採点は `src/photo.js`（画面上の位置・大きさ・顔の向き・ブレ・レイキャストによる隠れ判定・写っている散らかり）。
- 効果音と BGM は WebAudio でその場で合成しています（音源ファイルなし）。
- 物理は軽量な自前実装です（床の上の当たり判定、転倒アニメーション、倒れた先の巻き込み）。
- 画質は「きれい／ふつう／かるい」の3段階で、フレームレートが落ちると自動で下げます。静的な家具はまとめて描画して描画命令を減らしています。
- フォントは Google Fonts の「M PLUS Rounded 1c」（SIL Open Font License 1.1）を読み込み、読めない場合は端末のフォントを使います。
- Three.js は MIT ライセンスです。
