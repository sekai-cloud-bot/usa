# 駅まで、おむかえ。

おるすばん中の犬が、窓のすき間から脱走して、夕方の町をぬけ、18時の電車で帰ってくる飼い主を駅までむかえにいく 3D アドベンチャーです。
Three.js 製。PC とスマホのブラウザで遊べます。外部の画像・音声素材は使っていません（町・人・動物・空・音はすべてコードで生成）。

## 起動方法

必要なもの：[Node.js](https://nodejs.org/) 18 以上

```bash
git clone https://github.com/sekai-cloud-bot/usa.git
cd usa                       # ← package.json があるフォルダで実行します
git checkout claude/dog-game-threejs-mrp36o
npm install
npm run dev                  # http://localhost:5173 を開く
```

- スマホで試すとき：`npm run dev` は `--host` 付きなので、表示される `Network:` の URL を同じ Wi‑Fi のスマホで開きます。
- 公開用ファイル：`npm run build` で `dist/` に出力されます（相対パスなので GitHub Pages などのサブフォルダでも動きます）。`npm run preview` で確認できます。
- Windows で `ENOENT ... package.json` と出たら、`cd` でこのフォルダに移動してから実行してください。

## 遊び方

1. **プロローグ**：「6時の電車で帰るからね」。目がさめると、リビングの窓が少しあいています。鼻でおして庭へ。
2. **空撮のタイトル**：庭に出た瞬間、カメラが空へ上がって町と駅が見え、タイトルが出ます。
3. **脱出**：庭の柵の下のやわらかい土を掘って（長押し）、路地へ。
4. **においをたどる**：くんくんすると世界の色がぬけて、飼い主のにおいが金色の光の道になります。隠れた物も光ります。
5. **寄り道と友だち（8人）**
   - 路地：ゴミ置き場から塀に登って、塀の上のねこに会う／塀の上の「ぴかぴかの王冠」
   - 商店街：魚屋のおばあちゃんの前でおすわり（にぼしで足が速くなる）／花屋さんの前でおすわり（ひまわり）／アーチの上のカラスに王冠を見せる（赤いバンダナ）
   - さくら公園：茂みのボールを男の子に届ける（花かんむり）／柴犬に吠えて「おいかけっこ」／すべり台
   - 駅前通り：赤信号でおすわりすると、みどりのおじさんと友だち。信号が青になったら渡る（赤で渡ると車が止まってクラクション）
   - 駅前広場：ハトの群れに走りこむ／「まちあわせの犬」の像の台座に登る
6. **おむかえ**：改札の前でおすわりして待つと、夕焼けまで時間が進み、電車が高架に入ってきます。改札から出てきた飼い主にかけよると再会の演出。
7. **おむかえ日記**：再会の写真・おみやげ・友だち・寄り道がカードになり、シェア（Web Share）または画像保存ができます。

**くり返し遊ぶ理由**
- くわえて持っていった物（ひまわり／桜の枝／木の枝／王冠／ボール／なし）で、飼い主のセリフと日記が変わる（6種類）
- 友だち 8人・寄り道 5つを集める（結果画面に「まだ会っていない友だち」のヒント）
- もらったバンダナ・花かんむりは次回から身につけて出発
- いちばん早い到着時刻の記録

時間は 16:30 から進み、18:00 に電車が着きます。遅れても失敗にはならず、夕焼けのまま待っていてくれます。

## 保存されるもの（localStorage）

うちの子（名前・犬種・毛色・もこもこ）、出会った友だち、見たおみやげの種類、寄り道、もらったきせかえ、クリア回数、最速到着時刻、音と画質の設定。前作「うちの子、おるすばん中。」で作った子がいれば引き継ぎます。

## 画質

- 高：MSAA＋GTAO（環境光の遮蔽）＋ブルーム＋カラーグレーディング、影 2048
- 中（スマホの初期値）：GTAO なし、解像度 1.5 倍まで
- 低：ポスト処理なし、解像度 1 倍、影 1024
- 「自動」では 1 秒ごとに FPS を測り、38fps 未満が 3 秒続くと 1 段下げます。一時停止メニューから手動でも切り替えられます。

## しくみ（主なファイル）

| ファイル | 内容 |
|---|---|
| `src/adv/main.js` | 起動・ループ・画面遷移・画質の自動調整・タイトルの空撮 |
| `src/adv/game.js` | 物語の進行（コルーチン）・友だち・おみやげ・信号・駅と再会 |
| `src/adv/town.js` | 町の生成（家・庭・路地・商店街・公園・大通り・駅・遠景）と当たり判定 |
| `src/adv/props.js` `nature.js` | 家・店・電柱・自販機・木・草（風でゆれる）・池・桜吹雪 |
| `src/adv/actors.js` | 人・ねこ・カラス・ハト・カモ・車・電車・持ち物・きせかえ |
| `src/adv/player.js` `tpcam.js` `controls.js` | 犬の操作（ジャンプ・段差・塀の上）・三人称カメラ（壁よけ）・入力 |
| `src/adv/sky.js` `post.js` | 時刻で変わる空・太陽・霧・街の灯り（16:30 → 夕焼け → 夕闇）、ポスト処理 |
| `src/adv/fx.js` | きらきら・土ぼこり・においの道（1命令で描く粒） |
| `src/adv/share.js` `save.js` `ui.js` | おむかえ日記の画像・保存・HUD と字幕 |
| `src/dog.js` `src/dogModel.js` `src/room.js` `src/audio.js` | 犬のモデルと動き、リビング、効果音と BGM（WebAudio で合成） |

描画命令を減らすため、動かない建物や小物は地区ごとに頂点カラーで結合し、看板などの細かい物はカメラから遠い地区では描かないようにしています。
